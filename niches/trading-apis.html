Case file — Trading APIs

Prop Firm Risk Geometry

A backtest-driven Monte Carlo simulator that finds the prop-firm challenge configuration — strategy, risk-to-reward, and position sizing — with the best statistical odds of passing, then maximizing payouts once funded. It ingests 5-minute NQ/MNQ futures bars and backtests three intraday strategies (Opening Range Breakout, Mean Reversion, Trend Continuation) to extract real win rates and winner/loser distributions, then bootstraps thousands of Monte Carlo equity paths against the asymmetric $3K-target / $2K-drawdown account rules. Top configurations are independently re-validated with backtesting.py and rendered as EV breakeven curves, 3D pass-rate surfaces, and challenge/funded-phase payout heatmaps.

Case file — Trading APIs

TopstepX Daytrading Arena

AI agents go head-to-head against each other to compete on the best PnL they can obtain. Each agent gets their own simulated account and their trades are tracked and stored in a MySQL database. Incoming data feed from ProjectX TopstepX API is distributed to all agents via Kafka. Each agent has a hand crafted personality, from yolo trader to calculated momentum trader. Each model selected has function tooling capabilities and can do one of four functions: get available contracts, get historical data for contract, get portfolio, and open/close position.

Case file — Trading APIs

Topstep Algo Trade Engine

A full-stack algorithmic trading engine for TopstepX, Topstep's funded-account evaluation platform. A NestJS backend streams live market and account data over SignalR, runs event-driven trading strategies, and relays real-time updates to the client over Socket.IO. The Next.js dashboard tracks daily growth against the profit target and max-loss limit, live P/L, trade distribution by sector, and best/worst trades, charted with TradingView lightweight-charts. Fully containerized with Docker Compose.

Case file — Trading APIs

TopstepX API Client

A framework-agnostic TypeScript client for Topstep's TopstepX trading API, published on npm. It wraps the full REST surface — accounts, orders, positions, trades, contracts, and historical OHLCV bars — and layers real-time SignalR WebSocket feeds for live quotes, trades, market depth, and account/order/position updates. Ships with automatic token management and refresh, a complete set of typed interfaces and enums, dedicated error classes, and dual ESM/CommonJS builds, so it drops into any Node framework like Express, Fastify, or NestJS.

NinjaTrader Bridge

A bridge add-on that exposes NinjaTrader 8 — an otherwise GUI-only desktop trading platform — as a programmable REST API with real-time SSE and WebSocket streaming.
