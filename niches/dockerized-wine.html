Case file — Dockerized Wine

NinjaTrader Merlot

A Dockerized environment that runs NinjaTrader — a Windows-only futures trading platform — natively on Linux through the Wine compatibility layer. It packages a Wine prefix, the .NET/WPF runtime, Xvfb, and automated login into a reproducible image, exposing the desktop app through both a browser-based noVNC view and a native X11 display mode. Handles Tradovate brokerage authentication so the full trading platform runs headless in a container.
